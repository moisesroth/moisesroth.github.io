OAuth token acquisition (configuration reference)

The token endpoint, grant type and scope depend on the identity provider configured for your CPQ environment. This is a template, not a verified CPQ token endpoint.

POST https://YOUR-IDENTITY-PROVIDER/oauth2/v1/token
Content-Type: application/x-www-form-urlencoded

grant_type=client_credentials&client_id=YOUR_CLIENT_ID&client_secret=YOUR_CLIENT_SECRET&scope=YOUR_SCOPE

Use the access_token from the provider response as the Bearer token for CPQ calls, if your tenant supports this flow.
